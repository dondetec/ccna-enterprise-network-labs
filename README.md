# 🌐 CCNA Enterprise Network Labs

A hands-on Cisco networking portfolio documenting the design, configuration, verification, security, and troubleshooting of enterprise network technologies.

This repository is built around practical labs rather than configuration commands alone. Each lab documents the **objective, topology, addressing, configuration, verification, troubleshooting process, and lessons learned**.

---

## 🎯 Project Objectives

The goal of this repository is to strengthen and demonstrate practical skills in:

- Layer 2 switching
- VLAN segmentation
- 802.1Q trunking
- Inter-VLAN routing
- Spanning Tree Protocol (STP)
- EtherChannel / LACP
- IPv4 subnetting
- IPv6 networking
- Static and dynamic routing
- OSPF
- BGP fundamentals
- DHCP
- ACLs
- NAT / PAT
- Network security
- Network monitoring
- Troubleshooting
