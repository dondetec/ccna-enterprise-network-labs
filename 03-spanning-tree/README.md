
# Lab 03 — Spanning Tree Protocol

## Overview
This lab demonstrates Layer 2 loop prevention, root bridge election, redundant link failover, and Rapid PVST+.

## Technologies
- IEEE 802.1D Spanning Tree Protocol
- IEEE 802.1w Rapid Spanning Tree
- Cisco Rapid PVST+
- Root bridge election
- Designated, root, and alternate ports
- Layer 2 redundancy and failover

## Lab Files
- packet-tracer/STP.pkt — Classic STP
- packet-tracer/Lab-03-STP-Rapid-PVST.pkt — Rapid PVST+
- evidence/ — Verification and troubleshooting notes
- configs/ — Switch configurations

## Verification
Tested root bridge election, alternate-port blocking, primary-link failure, and restoration of the preferred path.
